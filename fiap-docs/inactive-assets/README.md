# Inactive Assets

Esta pasta é reservada para materiais futuros/experimentais que não fazem parte da lógica ativa do projeto.

Regras de uso:

- Não importar arquivos desta pasta em `src/`, `docs/` ou `docusaurus.config.js`.
- Não usar conteúdos desta pasta em rotas publicadas.
- Quando um asset ficar oficial, mover para o local correto (`static/`, `docs/` etc.).

Sugestão:

- Colocar aqui itens de template/exemplo que você quer guardar para referência futura.
